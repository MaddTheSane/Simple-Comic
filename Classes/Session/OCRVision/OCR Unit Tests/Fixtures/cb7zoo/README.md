# cb7 zoo (public-domain Jessie James pages only)

Built with `7zz a` from Public-Domain-Comic-Jessie-James.cbz pages (JJ1p01..JJ1p04 downscaled to 400 px, JPEG quality 40; "30pages" uses a 120 px page padded to distinct sizes). Whole set is about 330 KB, plain git.

| File | Options | Exercises |
|---|---|---|
| jj-4pages.cb7 | `-ms=off` | ordinary non-solid comic, 4 pages |
| jj-30pages.cb7 | `-ms=off` | 30 tiny pages, past the Quick Look preview's 25-page cap |
| jj-solid.cb7 | `-ms=on` | solid archive, 4 pages |
| jj-truncated.cb7 | jj-solid cut to 60% | broken archive; must not crash the preview |
| jj-empty.cb7 | add then delete a file | valid archive with no entries |
